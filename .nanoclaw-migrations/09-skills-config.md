# Skills & Configuration

**Intent:** OPJ1-specific skills (calendar, PDF, philosophy) and MCP server integrations for Oliver's professional domain (German labor law, social security, legal research).

## Custom Container Skills

### Calendar (`container/skills/calendar/`)

Copy directory as-is. Contains:
- `SKILL.md` — Slash command instructions
- `calendar.mjs` — Node.js script that fetches and parses iCal feed

**Commands:** `--today`, `--days N`, `--search "text"`
**Env var required:** `CALENDAR_ICAL_URL` in `.env` (Google Calendar private iCal URL)

### PDF Reader (`container/skills/pdf-reader/`)

Copy directory as-is. Contains:
- `SKILL.md` — Usage instructions
- `pdf-reader` — Shell script wrapping pdftotext

**Commands:** `extract <file>`, `fetch <url>`, `info <file>`, `list`
**Requires:** `poppler-utils` in Dockerfile (see section 5)

### Philosophie-Feed (`container/skills/philosophie-feed/`)

Copy directory as-is. Contains:
- `SKILL.md` — Instructions with academic framing for content filter safety

**Data source:** `/workspace/extra/shared/philosophie_today.json` (mounted from `/opt/shared/`)
**Generated by:** External cronjob (opj2bot user, 08:00 daily)

### Host-side Philosophie-Feed (`.claude/skills/philosophie-feed/`)

Copy directory as-is. Simplified version for host-level Claude Code sessions.
